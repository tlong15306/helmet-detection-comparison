# Prediction Faster R-CNN

## Lưu gì tại đây

- Ảnh test có bounding box, nhãn và confidence dự đoán.
- Ví dụ true positive, false positive và false negative.
- Có thể lưu video demo ngắn nếu dung lượng phù hợp và không đưa lên Git.

## Quy tắc chọn ảnh báo cáo

- Dùng checkpoint và threshold được ghi rõ.
- Không chỉ chọn các trường hợp đẹp; cần có phân tích lỗi đại diện.
- Không dùng ảnh train để minh họa chất lượng tổng quát như ảnh test.
- Giữ tên ảnh/image ID để truy ngược ground truth.
